# 隐私说明

一句话：没有账号，没有作者服务器。你问的东西先到本机 DSH，再由 DSH 发给你自己配置的模型。

适用版本：扩展 0.4.4 / 后端插件 0.2.0。

## 收什么

不收。

- 不收集账号、邮箱、浏览历史、剪贴板、键盘输入、使用统计、崩溃报告。
- 没有广告，没有追踪像素，没有向作者或第三方上报数据的代码。
- 扩展里唯一写死的网络地址是 `http://127.0.0.1:3080`。

## 发什么

| 什么时候 | 发什么 | 发到哪 |
| --- | --- | --- |
| 提问 | 你选中的文字、框选的截图、你打的问题 | 本机 `127.0.0.1:3080/page-chat/ask` |
| 记住这段 | 这段对话原文、当前页标题和网址、截图（如果有） | 本机 `/page-chat/memorize` |
| 存成看板卡 | 这段对话（最多 20 条）、问题、页面标题和网址 | 本机 `/page-chat/to-board`，再转给看板插件 `/pydsl/dsh-board/clip` |
| 压记忆卡 | 这段对话原文 | DSH 当前配置的模型接口 |
| 回答 | 系统提示 + 这段对话的上下文 | DSH 当前配置的模型接口 |

- 模型接口由你在 DSH 里配置，可能是本机服务，也可能是远程 API。数据是否离开本机、服务商是否留存，取决于你选的服务，不取决于这个插件。
- 网页侧会话被限制成 0 个工具：网页内容不能反过来让插件读文件、跑命令或访问别的东西。
- 请求体上限 20MB；太大的截图会被拒绝。

## 存什么

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 记忆卡 | `~/.dsh/page-chat-memory/cards/*.json` | 标题、摘要、要点、标签、站点、来源网址、时间 |
| 对话原文 | `~/.dsh/page-chat-memory/cards/*.thread.jsonl` | 点「记住这段」时才写 |
| 截图 | `~/.dsh/page-chat-memory/cards/*.png` | 你框选过图才会存 |
| 同步配置 | `~/.dsh/page-chat-sync/.sync.json` | 开关、仓库地址、令牌或密码（明文） |
| 扩展侧 | 当前标签页的 `sessionStorage` | 会话号、面板位置；关标签页即清 |

- 扩展清单里申请了 `storage` 权限，但当前版本只用了标签页的 `sessionStorage`，没有往 `chrome.storage` 写东西。
- 记忆卡是普通 JSON，可以自己打开看、搜索、打包带走。
- DSH 自己的会话日志和模型配置不在这个目录，按 DSH 的说明管理。

## 怎么删

### 删一张

DSH Web 侧栏 →「网页记忆」→ 打开卡片 → 删除。删除后卡片标成 `deleted`，对话原文和截图一起清掉。

### 删一个站

在「网页记忆」面板里选中站点，点「清空这个站」。

### 全删

1. 退出 DSH。
2. 删除 `~/.dsh/page-chat-memory/`。
3. 如果开过云同步，再删 `~/.dsh/page-chat-sync/`；这一步会把令牌一起删掉。
4. 云端副本要去你的 GitHub 私有仓库或 WebDAV 目录里删。插件删除卡后会写删除标记，下次同步会传播，但不保证立即。

### 卸载扩展

在浏览器扩展管理页移除「随手问」。当前标签页的 `sessionStorage` 随标签页关闭清空。

## 云同步（可选，默认关）

- 只支持两种：GitHub 私有仓库、WebDAV。
- 默认只同步卡片和对话原文；截图默认不同步（`syncShots: false`）。
- **令牌明文存本地**：GitHub token 或 WebDAV 密码写在 `~/.dsh/page-chat-sync/.sync.json`，没有加密；能读这个文件的人就能读令牌。
- 建议用只给一个私有仓库权限的细粒度令牌（fine-grained token），或专用的 WebDAV 账号，不要用主账号令牌。
- 同步请求从你的电脑直接发到 GitHub 或你的 WebDAV，不经过作者服务器。
- 删除会写成删除标记同步出去。两边都改了同一张卡时，插件不猜，会留一份带设备名的副本。
